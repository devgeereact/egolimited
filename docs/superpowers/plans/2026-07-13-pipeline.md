# Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Campaigns + Leads + Automation into one Pipeline, where `ego_customers` is the single contact table, stages are derived from facts, and four automations plug the four leaks that cost EGO money.

**Architecture:** `ego_customers` gains lifecycle columns (`stage`, `source`, `owner_id`, `next_action_at`, `stage_locked`). Stage is **computed** from facts already in the database (replied → interested, open quote → quoted, paid invoice → customer, no job in 12 months → dormant), never hand-maintained. Leads migrate into `ego_customers` as `stage='prospect'`; campaign enrolments re-point by email. The website enquiry form starts creating a *contact* (not only an inbox row). Automations reuse the Campaigns v2 send queue and suppression list.

**Tech Stack:** PHP 8 (vanilla, no Composer) + MySQL/MariaDB · React 19 + TypeScript + Vite + TanStack Query + Tailwind/shadcn · vitest + a zero-dependency PHP test harness (`api/tests/run.php`).

## Global Constraints

- **Prepared statements only.** Never interpolate request data into SQL. Use `db_one` / `db_all` / `db_exec` from `api/lib/db.php`.
- **Read `affected_rows` from the STATEMENT** (`db_exec(...)->affected_rows`), never from the connection — the connection lies about prepared executes.
- **Every new route MUST be registered in `api/lib/authz.php`.** The gate is fail-closed: unregistered routes 404. `api/tests/run.php` has a drift guard that fails the build if the manifest and the handlers disagree.
- **`schema.sql` is the source of truth.** No `CREATE TABLE` at runtime inside PHP.
- **Automation drafts and prompts; a human sends and decides.** No new code path may send email to a customer or prospect without an explicit human action, with ONE deliberate exception: the enquiry auto-acknowledgement (Task 5), which the owner approved.
- **Suppression is checked before every send** (`supp_has()` in `api/lib/campaigns.php`). No exceptions.
- **No deal values, no forecasting, no lead scoring, no assignment rules.** Out of scope by design.
- Verify with `php api/tests/run.php`, `cd app && npx tsc -b && npm test && npm run lint`. Lint is a blocking CI gate: 0 errors.

```php
<?php
/**
 * EGO LIMITED — the pipeline domain. See docs/superpowers/specs/2026-07-13-pipeline-restructure-design.md
 *
 * A prospect is a customer who hasn't bought yet. There is ONE contact table.
 *
 * The stage is DERIVED, never hand-maintained. A hand-kept board rots the first time someone
 * forgets to drag a card, and then it lies quietly forever. A derived board cannot lie, because it
 * reads the same facts the invoices read.
 */
declare(strict_types=1);

/** Ranked most-decisive first: a paid invoice outranks a quote, which outranks a reply. */
function stage_for(array $f): string {
    $now = strtotime((string)($f["now"] ?? "now"));

    if (!empty($f["has_paid_invoice"])) {
        $last = !empty($f["last_job_at"]) ? strtotime((string)$f["last_job_at"]) : null;
        if ($last !== null && $last < strtotime("-12 months", $now)) return "dormant";
        return "customer";
    }
    if (!empty($f["has_open_quote"])) return "quoted";
    if (!empty($f["quote_declined"])) return "lost";
    if (!empty($f["has_replied"])) return "interested";
    if (!empty($f["has_outbound"])) return "contacted";
    return "prospect";
}
```

- [ ] **Step 1: Add to `api/lib/pipeline.php`**

```php
/** Gather the facts a stage is derived from. One query per fact, all indexed. */
function stage_facts(mysqli $db, int $id): array {
    $paid = db_one($db, "SELECT 1 x FROM ego_invoices WHERE customer_id=? AND kind='invoice' AND status='paid' AND deleted_at IS NULL LIMIT 1", "i", $id);
    $open = db_one($db, "SELECT 1 x FROM ego_invoices WHERE customer_id=? AND kind='quote' AND status IN ('draft','sent') AND deleted_at IS NULL LIMIT 1", "i", $id);
    $dead = db_one($db, "SELECT 1 x FROM ego_invoices WHERE customer_id=? AND kind='quote' AND status='declined' AND deleted_at IS NULL LIMIT 1", "i", $id);
    $in   = db_one($db, "SELECT 1 x FROM ego_messages WHERE customer_id=? AND direction='inbound' LIMIT 1", "i", $id);
    $out  = db_one($db, "SELECT 1 x FROM ego_messages WHERE customer_id=? AND direction='outbound' LIMIT 1", "i", $id);
    $job  = db_one($db, "SELECT MAX(created_at) j FROM ego_jobs WHERE customer_id=? AND deleted_at IS NULL", "i", $id);
    return [
        "has_paid_invoice" => (bool)$paid,
        "has_open_quote"   => (bool)$open,
        "quote_declined"   => (bool)$dead,
        "has_replied"      => (bool)$in,
        "has_outbound"     => (bool)$out,
        "last_job_at"      => $job["j"] ?? null,
    ];
}

/** Recompute and persist. A human override (stage_locked) always wins. */
function stage_recompute(mysqli $db, int $id): string {
    $c = db_one($db, "SELECT stage, stage_locked FROM ego_customers WHERE id=?", "i", $id);
    if (!$c) return "";
    if ((int)$c["stage_locked"] === 1) return (string)$c["stage"];

    $stage = stage_for(stage_facts($db, $id));
    if ($stage !== $c["stage"]) {
        db_exec($db, "UPDATE ego_customers SET stage=? WHERE id=?", "si", $stage, $id);
        contact_log($db, $id, "stage", "Moved to " . $stage);
    }
    return $stage;
}

/** One line on the business's timeline. */
function contact_log(mysqli $db, int $id, string $kind, string $summary, ?int $actorId = null): void {
    db_exec($db, "INSERT INTO ego_contact_events (customer_id, kind, summary, actor_id) VALUES (?,?,?,?)",
        "issi", $id, $kind, mb_substr($summary, 0, 250), $actorId);
    db_exec($db, "UPDATE ego_customers SET last_activity_at=NOW() WHERE id=?", "i", $id);
}
```

### Task 3: Migration — leads become contacts

**Files:**

- [ ] **Step 1: Create `api/migrate_pipeline.php`**

```php
<?php
/**
 * One-shot, idempotent, CLI-only. Leads become contacts; enrolments re-point by email; every
 * existing customer's stage is derived from facts. ego_leads is KEPT (read-only) so this is
 * reversible for one release — same discipline as the procurement tables.
 *
 * Run: php api/migrate_pipeline.php
 */
declare(strict_types=1);
if (PHP_SAPI !== "cli") { http_response_code(404); exit; }

$cfg = require __DIR__ . "/config.php";
mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);
$db = new mysqli($cfg["db_host"], $cfg["db_user"], $cfg["db_pass"], $cfg["db_name"]);
$db->set_charset("utf8mb4");
require_once __DIR__ . "/lib/db.php";
require_once __DIR__ . "/lib/pipeline.php";

$moved = 0; $merged = 0; $repointed = 0; $staged = 0;

foreach (db_all($db, "SELECT * FROM ego_leads WHERE email IS NOT NULL AND email <> ''") as $l) {
    $email = strtolower(trim((string)$l["email"]));
    $existing = db_one($db, "SELECT id FROM ego_customers WHERE LOWER(email)=? AND deleted_at IS NULL", "s", $email);

    if ($existing) {
        // Already a customer. Don't duplicate them — that is the entire point of this migration.
        $cid = (int)$existing["id"];
        $merged++;
    } else {
        $name = trim((string)($l["company"] ?: $l["name"] ?: $email));
        db_exec($db,
            "INSERT INTO ego_customers (name, company, email, website, notes, stage, source)
             VALUES (?,?,?,?,?, 'prospect', 'cold')",
            "sssss", $name, $l["company"], $email, $l["website"], $l["note"]);
        $cid = (int)$db->insert_id;
        contact_log($db, $cid, "note", "Imported from leads (" . ($l["status"] ?? "found") . ")");
        $moved++;
    }

    // Enrolments follow the person, by email — same address, same history, no orphans.
    $st = db_exec($db, "UPDATE ego_campaign_enrollments SET lead_id=NULL WHERE LOWER(email)=?", "s", $email);
    $repointed += $st->affected_rows;
}

// Every existing customer gets a stage derived from facts. Nothing is hand-classified.
foreach (db_all($db, "SELECT id FROM ego_customers WHERE deleted_at IS NULL") as $c) {
    stage_recompute($db, (int)$c["id"]);
    $staged++;
}

echo "moved {$moved} · merged into existing {$merged} · enrolments repointed {$repointed} · stages derived {$staged}\n";
```

### Task 5: The enquiry stops being just an email  ← THE BIGGEST LEAK

**Files:**
- Modify: `api/index.php` (`POST /enquiry`)
- Modify: `api/lib/pipeline.php`

**Interfaces:**
- Produces: `contact_upsert_by_email(mysqli $db, array $r): int` — returns the customer id, creating one if the email is new. `$r`: `email` (required), `name`, `company`, `phone`, `source`.

- [ ] **Step 1: Add the upsert to `api/lib/pipeline.php`**

```php
/**
 * Find this business by email, or create it. The ONE way a contact enters the system, so an
 * enquiry, a phone call and a cold lead all land in the same place and can never diverge into
 * two records for one business.
 */
function contact_upsert_by_email(mysqli $db, array $r): int {
    $email = strtolower(trim((string)($r["email"] ?? "")));
    if ($email === "" || !filter_var($email, FILTER_VALIDATE_EMAIL)) return 0;

    $found = db_one($db, "SELECT id FROM ego_customers WHERE LOWER(email)=? AND deleted_at IS NULL", "s", $email);
    if ($found) return (int)$found["id"];
```

### Task 7: Automations — the cron

**Files:**

- [ ] **Step 1: Create `api/pipeline_cron.php`**

```php
<?php
/**
 * EGO LIMITED — pipeline automations. CLI only. Cron: hourly.
 *
 * The governing rule, from the spec: AUTOMATION DRAFTS AND PROMPTS; A HUMAN SENDS AND DECIDES.
 * Nothing in this file emails a customer. It moves stages, raises deadlines, and puts work in
 * front of a person. The one approved exception (the enquiry auto-acknowledgement) is sent by
 * POST /enquiry itself, at the moment of the enquiry, because an hour late is not an acknowledgement.
 */
declare(strict_types=1);
if (PHP_SAPI !== "cli") { http_response_code(404); exit; }

$cfg = require __DIR__ . "/config.php";
mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);
$db = new mysqli($cfg["db_host"], $cfg["db_user"], $cfg["db_pass"], $cfg["db_name"]);
$db->set_charset("utf8mb4");
require_once __DIR__ . "/lib/db.php";
require_once __DIR__ . "/lib/pipeline.php";

$restaged = 0; $chases = 0; $dormant = 0;

/* 1. Every contact's stage, re-derived. Cheap, and it means the board can never drift from
 *    the facts even if an event was missed. */
foreach (db_all($db, "SELECT id FROM ego_customers WHERE deleted_at IS NULL AND stage_locked=0") as $c) {
    stage_recompute($db, (int)$c["id"]);
    $restaged++;
}

/* 2. Quote sent, no answer. The most expensive leak in a maintenance firm: you quote £2,400,
 *    hear nothing, and the job goes to whoever bothered to chase. We do not send the chase —
 *    we put it in front of a human, because a chase in the wrong tone loses the job. */
foreach (db_all($db,
    "SELECT i.id, i.customer_id, i.number, i.total, i.sent_at, c.name
     FROM ego_invoices i JOIN ego_customers c ON c.id = i.customer_id
     WHERE i.kind='quote' AND i.status='sent' AND i.deleted_at IS NULL
       AND i.sent_at IS NOT NULL
       AND i.sent_at < DATE_SUB(NOW(), INTERVAL 3 DAY)
       AND (c.next_action_at IS NULL OR c.next_action_at < NOW())") as $q) {
    $cid = (int)$q["customer_id"];
    $days = (int) floor((time() - strtotime((string)$q["sent_at"])) / 86400);
    db_exec($db, "UPDATE ego_customers SET next_action_at = NOW() WHERE id=?", "i", $cid);
    contact_log($db, $cid, "quote_sent",
        "Quote {$q['number']} sent {$days} days ago, no answer — chase it");
    $chases++;
}

/* 3. Dormant customers. The cheapest work EGO will ever win: they already trust us. */
foreach (db_all($db,
    "SELECT id, name FROM ego_customers
     WHERE deleted_at IS NULL AND stage='dormant' AND stage_locked=0
       AND (last_activity_at IS NULL OR last_activity_at < DATE_SUB(NOW(), INTERVAL 30 DAY))") as $c) {
    contact_log($db, (int)$c["id"], "note", "Gone quiet for over a year — worth an offer?");
    $dormant++;
}

echo date("c") . " restaged {$restaged} · quote chases raised {$chases} · dormant flagged {$dormant}\n";
```
