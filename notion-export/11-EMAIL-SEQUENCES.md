Ready-to-use marketing and lifecycle email sequences for EGO LTD. These are separate from the app's transactional emails (job-complete alerts, invoice reminders). Send them through the campaigns bulk-email feature. Tone: plain, British, proof-led, written like the owner, not a marketer. Swap the `{{tokens}}` for real values before sending, and only ever quote real jobs, real figures and real reviews.

## How to use this doc

- Each email has a subject line, preview text, body and a single clear CTA.
- Replace every `{{token}}` (see the personalisation list at the bottom). If a token is empty, cut the line — never send "Hi {{first_name}}".
- Payment is bank transfer only. Notifications are email only. Don't promise SMS or card payment anywhere.
- One CTA per email. The CTA is usually: reply, call **07539 705576**, or open the job-tracking link.
- Keep the signature short and human. Default sign-off below; adjust the name to whoever actually sends.

## Sending cadence

Spacing matters more than volume. Stop any sequence the moment the contact replies, books, or accepts — never let a "still thinking?" land after they've said yes.

| Sequence | Email | Send timing |
|---|---|---|
| 1. Homeowner enquiry | 1 Thanks | Immediately on enquiry |
| | 2 Quote | When quote is ready (aim within {{quote_turnaround}}) |
| | 3 Quote nudge | 2–3 days after quote |
| | 4 Still thinking? | 5–7 days after quote |
| 2. B2B cold outreach | 1 Intro | Day 0 |
| | 2 Value/proof | Day 4 |
| | 3 Portfolio case | Day 9 |
| | 4 Social proof | Day 15 |
| | 5 Breakup | Day 22 |
| 3. Landlord nurture | 1 Why a partner | Day 0 |
| | 2 Per-property record | Day 5 |
| | 3 Planned upkeep | Day 11 |
| 4. Post-job | 1 Review | 1–2 days after completion |
| | 2 Referral | 7 days after completion |
| 5. Win-back | 1 Hello | When dormant ({{months_since_last_job}}+ months) |
| | 2 To-do list | 7 days after email 1 |
| 6. Seasonal | Winter prep | Mid-Sept to mid-Oct |
| | Pre-let refurb | Quarterly, or when a void is flagged |

General rules:
- **Send weekday mornings** (Tue–Thu, 8–10am) for B2B; homeowners are fine evenings and weekends.
- **One sequence per contact at a time.** Don't run nurture and a seasonal blast at the same person in the same week.
- **Quiet anyone who's mid-job.** They're already getting transactional emails — don't pile marketing on top.
- **Honour opt-outs immediately** and keep a suppression list. Every marketing email needs an unsubscribe line.

| `{{quote_turnaround}}` | Quote promise window | 2 working days |
| `{{earliest_slot}}` / `{{seasonal_slot}}` | Next available date | next Thursday |

| `{{property_or_premises}}` | "your home" / "the premises" | your flat |
| `{{example_job}}` / `{{example_outcome}}` | Real proof point (B2B) | a flooded utility room / dried, repaired and re-tiled in two days |
| `{{reference_client_type}}` | Type of client for proof | managing agents |
| `{{testimonial_quote}}` / `{{testimonial_name}}` | Real review + attribution | "Turned up when they said..." / J. Okafor, landlord |
| `{{review_link}}` | Your review page URL | egolimited.com/review |

> Only use real figures, real jobs and real reviews. Made-up proof is worse than none — it's the fastest way to lose a B2B account.
